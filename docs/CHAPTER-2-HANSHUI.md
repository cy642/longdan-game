# 第二章设计稿：汉水孤营

《龙胆：逆命三国》｜宣传副标题：重生之我在三国当赵子龙

状态：设计阶段，尚未加入正式试玩。平台为电脑，继续使用 Godot 原生 2D 俯视角、现有 Q 版赵云与键鼠操作。

## 玩家要体验什么

赵云接应劫粮未归的黄忠，带残军回营，主动大开营门。玩家亲自压住门前试探，藏住援军，在曹军迟疑退却时擂鼓反击，最后击败追兵督军。

本章让“带兵”产生具体作用：赵云负责破阵、断后和击杀，随军守住战术点，弩阵提供一次由玩家发动的反击机会。重点是亲手把追击战变成自己的局。

全章目标体验时长 25–35 分钟；第一个可玩样段目标 10–12 分钟。时长和下文数值是初始设计目标，完成试玩后再校准。

## 剧情承接与改编边界

章首明确显示“建安二十四年 · 汉水”，用三幕短过场交代长坂之后的年月、赵云的军职与本次接应任务。玩家保留“知道旧事”的心声，赵云的判断通过对白与实际军令表现。

文献线索包括黄忠取粮逾期、赵云出营接应、回救受伤的张著、大开营门、曹军疑伏退却，以及擂鼓与弩射反击，见《三国志》赵云传裴注所引《云别传》。本章据此安排战役骨架。具体地图、黄忠接应战、伤兵支线、战术判定和“铁面督军”均为游戏改编；铁面督军是原创角色。[原文出处](https://zh.wikisource.org/wiki/三國志/卷36#趙雲)

本章的“逆命”目标落在撤军中的伤兵和村寨：玩家可回救张著及伤兵、保住撤退粮车、截断追击军的火攻准备。战报记录这些选择带来的结果。

第一章的三个命运标记用于家书、医者对白与营中见闻。它们增加承接感。所有玩家都能完成汉水主线，初始战斗数值统一，青釭在本章可用。

## 核心场面：亲手完成空营计

### 1. 布置

营门前的两个点可按 E 查看：“藏兵旗”和“鼓台”。张翼用一句话提醒玩家：随军藏入侧寨，赵云守住正门。按 2 将随军留在藏兵旗附近，按 E 选择开门。

此时存下战术检查点。门外只生成首批 2 名试探兵，HUD 显示“守住营门 · 击退试探 0 / 2”。

### 2. 门前压阵

玩家击退两批试探兵，每批最多 2 人。连续攻击、绕盾和精准闪避都能完成目标，主线允许玩家用熟悉的战斗方式处理。

随军守在侧寨，玩家越过营门时仍可移动和出招。试探兵突破门线后，由侧寨军士截住一人，玩家获得重新站稳的空间；计策阶段保留当前进度，追加最多 2 人的补救遭遇，总出兵有限。

### 3. 敌军迟疑

试探结束，前排敌军停止冲锋并向河湾后退。音乐降低，寨旗落下，赵云仍可操控。镜头轻微拉宽，显示退军方向与鼓台位置，HUD 提示“敌军退却 · 到鼓台擂鼓反击”。

### 4. 玩家发令

敌军退到标记线后，鼓台金圈亮起，提供约 4 秒的最佳反击窗口。玩家按 E 擂鼓，侧寨弩兵向已标记敌群齐射一次，形成破势机会；随军出寨牵制，赵云切入敌阵。

援军齐射的初始伤害为 35，普通兵击杀仍由玩家完成；督军不受这次齐射影响。战机错过后鼓台仍可触发较弱反击，或者直接近战清开河湾。两条打法都能推进章节。

战报分别记录“空营震敌”与“正面破围”。重复敲鼓只播放交互提示，同一场计策不会反复生成弩射或援军。

## 军令如何变得有用

沿用 1 集合、2 守点、3 冲阵。玩家始终直接操纵赵云，一组三名随军提供掩护。

| 军令 | 第二章的具体用途 | 对战斗的约束 |
|---|---|---|
| 集合 | 穿过乱石小路、脱离弩兵射线，跟随赵云转移 | 随军输出沿用 3.5 伤害 / 1.8 秒；敌人体力最低保留 22% |
| 守点 | 守粮车停靠处或藏兵旗，阻挡一名追兵，保持撤军路线 | 有限牵制；倒地后失去守点效果，赵云需要回援 |
| 冲阵 | 在擂鼓后逼近指定敌群，为赵云切弩兵创造位置 | 军令改变站位和目标；普通兵击杀交给玩家 |

黄忠在接应战中主要负责压住自己的出口，张翼负责提醒和执行藏兵、开门命令。铁营决战阶段随军留在外围守住退路，赵云与督军交战。

## 敌人设计

| 敌人 | 玩家能读到的动作 | 初始参数与克制方法 |
|---|---|---|
| 双刀斥候 | 左肩压低后快速两斩；第二斩后有明显收势 | 体力约 75；起手约 0.5 秒，整套结束留 0.9 秒反击；绕背或等两斩结束 |
| 汉水弩兵 | 举弩、锁线、双发，随后收弩装填 | 体力约 65；起手约 0.9 秒，双发间隔 0.25 秒，装填约 1.4 秒；石墙和树挡箭 |
| 铁甲盾兵 | 盾缘前倾、短距离盾撞，转身较慢 | 体力约 140；横扫破盾、侧翼刺击；混编时优先处理后排弩兵 |
| 铁面督军 | 黑甲、铜环与钩镰斧，起手沉重，变招有明确轮廓 | 初稿体力 1450；可玩样段先用 1000。破势初稿 135，半血变招；数值以实测为准 |

普通遭遇通常 3–5 人，同屏活跃战斗人数目标不超过 8。增援按批出现，先给方向提示，再进入可见范围。弩线、刀弧与实际命中范围一致。

### 督军招式初稿

| 招式 | 识别点与判定 | 起手 / 主要反击空间 |
|---|---|---|
| 钩锁探身 | 举斧到肩后，沿窄线近距离钩拉 | 约 0.95 秒起手；侧闪成功后留 1.1 秒；拉扯落点受地形碰撞限制 |
| 双轮重斧 | 横斩接迟势回斩；第二斩前短暂停顿 | 首斩约 0.75 秒，回斩延迟约 0.45 秒；整套结束留 1.3 秒 |
| 撼地断营 | 双手举斧砸地，扇区边界在出手前完整显示 | 约 1.2 秒起手，约 1.5 秒收招；离开扇区后切入反击 |
| 半血：断锁追斩 | 铜环崩落，先短冲、再扫身；保留原有识别动作 | 变招过渡约 1.1 秒；短冲约 0.6 秒起手，完整连招结束再提示可反击 |

钩拉只有实际命中才移动赵云，闪避的无敌时段与精准闪避仍生效。河岸设可见碰撞边界，冲撞保留恢复空间。Boss 决战场地至少留出两条绕行路线，受击和失败后都从门前重试。

## 探索、逆命与奖励

- **伤兵谷：回救张著。** 玩家回身清开追兵，张著与两名伤兵沿安全路径退回营地。奖励营内捷径和一段赵云、张著的对白；战报记为“伤兵归营”。
- **烽火岗：截断火攻。** 击退弩兵和盾兵后破坏火箭辎重，河湾阶段撤掉一组火箭压制。战报记为“粮车保全”。
- **营门战机：空营震敌。** 完成开门、藏兵与最佳时机擂鼓。奖励招式“龙胆·回澜”的解锁资格；全章通关后获得，供章节重玩或第三章使用。

“回澜”沿用 Q 的位置，计划做成可切换的横扫变式：扫开近身敌人并提高破势，气力消耗仍从现有技能预算调校。第一个可玩样段先用原横扫，待计策循环成立后再实现招式变式。

完成任意主路线即可进入结局。支线改变对白、河湾难度和战报条目，奖励集中在战术机会与可选招式。

## 美术与声音

延续当前 Q 版国风比例。赵云保持蓝披风与银甲；黄忠用黄褐披风、长髯和弓的轮廓，督军以黑甲、铜环、宽斧建立辨识度。

汉水环境以灰蓝水色、深绿竹林、湿石、木寨和暖色篝火区分区域。道路和关键战术点可辨，雾层保持轻薄，红色预警始终位于雾层之上。营门前由静到动的旗帜、鼓台、弩阵和退军构成本章的主要场面。

声音先延续本轮已调整的轻脚步：跑图音靠后，武器和危险预警靠前。风声、水声低音量循环；营门迟疑时收掉环境高潮，擂鼓反击使用一次清晰鼓点。弩兵装填和督军钩锁使用不同短音，帮助玩家判断收招。

首批美术优先级：营门与鼓台、石墙和竹林、弩兵动作、督军动作、黄忠与张著。新敌人先做四方向的起手 / 命中 / 收势，每段至少两帧，再补行走和受击；导入前核对独立帧边界、头部尺度和脚底位置。

## 代码接入与进度兼容

现有工程的区域读取、目标、Boss、存档验证和地图尺寸仍针对第一章。增加 `chapter2.json` 之前，需要把章节索引、初始技能和章节完成记录接入这些位置。

- 存档升级为版本 2，保存每章独立的检查点、命运标记和战报。版本 1 长坂存档只迁移到第一章记录，保留原完成状态与进度；迁移成功后写新文件，旧文件保留作回退。
- 用 `TacticDirector` 管理营门状态：准备 → 试探一 → 试探二 → 退军 → 最佳反击 / 普通反击 → 完成。状态推进以实际击退、位置和交互事件为条件，暂停时冻结时机。
- 援军齐射、支线奖励和战术开门都记录“一次完成”标记；死亡重试恢复当前阶段的敌人，已完成救援与支线保留。
- 第一份样段提供独立测试入口并使用独立进度，默认拥有青釭。正式接入标题页时提供章节选择，完成第一章后开放第二章。
- 沿用烘焙地表、共用景物图集和桌面 Web 分辨率上限。先保持现有地图尺寸，雾、雨和新动画逐项加入后测量；常态最多 8 名活跃敌人、3 名随军，粒子数量设置上限。

## 必须跑通的体验场景

1. 玩家只做主线，可以接应黄忠、回营、破围、打败督军并获得战报。
2. 玩家不会熟练发布军令，张翼的提示与战术点仍能帮助其完成第一次计策。
3. 随军不能独自清场；赵云需要亲自处理试探、弩兵和关键击杀。
4. 错过最佳擂鼓时机仍有可通关路径，援军齐射与奖励不会重复触发。
5. 粮车或伤兵遭遇失败，可以从当前落脚点重试，完成的支线不会被抹掉。
6. 暂停、掉帧和存档恢复后，计策不会跨过关键状态或把门永久关死。
7. 每种敌人的出手方向、预警、实际命中与受击动作一致；河岸、营门和石墙碰撞可靠。
8. 第一章原存档可继续；第二章设计文件和测试入口不会改变现有正式试玩进度。

## 本轮第一章收尾记录

已实施：脚步声独立播放，比原来的音效通道降低 12 dB；噪声经过两级低通，落脚音有小幅变化。赵云落脚间距由 32 调整为 56 个世界像素，行走姿势与落脚同步，扬尘更轻。攻击移动时武器声优先。暂停页增加脚步声独立开关，静音立即停止正在播放的声音。
