# 龙胆：逆命三国 · 可玩性与双章连贯体验

2026-10-20，在 `0c92f3f` 的美术版基础上打磨。本文把当前已实现的玩法闭环与后续设计目标分开；不是对人工通关时间或商业成绩的承诺。

## 核心体验

玩家要从“跟着金标清兵”变成“看招、决定连击或闪避、抓机会破阵，再决定路线与军令”。每段战斗提供一个能主动争取的小目标，每个区域用不同任务改变操作，章节完成后自然进入下一场战役。

当前主要问题来自源码与实际流程：普通兵每次轻击都会取消出手，持续按 J 的代价太低；青釭之后缺少可选打法；粮车比赵云慢得多且下一波只能等车触发；第一章战报默认返回标题，第二章按钮会走重开流程。

## 本轮已实现

### 战斗中的小循环

枪势为 0–3 格，和青釭战意分开。第三枪真正造成伤害、或精准闪避成功，各积 1 格；同一次攻击打到多名敌人仍只积一次，挥空、隔墙和零伤害盾挡不能刷势。普通受击掉 1 格，死亡、休整、切图清空，不存为永久资源。

满三格后，下一次 Q 自动消耗枪势：范围乘 1.18，破势乘 1.6，基本伤害与气力消耗不变。玩家需要决定是否打满三式，以及何时把范围与破势收益用于盾阵或敌将。强化兼容已有的「龙胆·回澜」，不覆盖其独立解锁。

杂兵第一次被轻击打断后有 0.65 秒防重复打断，期间仍会掉血、继续原有红区预警；Q、R 和破势仍能中断。它防止按住普攻永久压制，不是免伤或取消攻击预警。Boss/校尉原有抗打断规则保留。

### 营火选择打法

安全营火恢复资源后打开整备页，战斗与战术计时暂停；Esc 或“继续前行”可直接退出。两种战法互斥，可以在营火免费调整：

| 战法 | 具体效果 | 鼓励的操作 |
|---|---|---|
| 连锋 | 第三枪命中积 2 格枪势 | 打满三式、判断继续压制还是闪开 |
| 游龙 | 精准闪避积 2 格，回马枪首次命中回 12 气力 | 观察敌方出手、闪避后立即反击 |

普通枪法依然能使用整个枪势循环。选择按章保存，旧 v1/v2 存档自动使用基础枪法；首次从通关长坂进入汉水会承接所选战法，已有汉水进度使用它原来的独立选择。不能在战斗中从暂停菜单随意换装。

### 汉水从等车变成主动开路

玩家接近下一道路障即可提前引出该波，清路后让粮车跟上。每次只激活第一个未完成路障，不会同时刷完所有敌人或跳过实际路线。

粮车安全段常速 112，赵云在前方时渐进追赶至 164，护送范围 520；附近有敌或离队太远仍停车。三次路障、160 耐久、实际碰撞、车毁重试和伤兵支线保留。目标提示会区分战斗阻拦、离队停等、卡住和正常前进，按实际原因指向车、敌人或下一路障。

藏兵显示当前人数，门前显示波次和剩余敌人，退军阶段提醒回鼓台。最佳鼓点、错过后普通齐射与破计后正面反击有不同提示。阻车提示只在首次达到阈值时出现，避免不断覆盖其他提示。

### 两章连续推进

第一章通关先保存战报，首按钮为“继续征程 · 汉水孤营”。首次进入通过明确的年代与军情对白连接两场战役，承接难度和所选战法。已有第二章进度直接继续，已完成则查看汉水战报；都不覆盖原进度。第一章战报始终可从标题重看。

## 关卡节奏总规划

| 区域 | 体验重点 | 当前实现及下一步 |
|---|---|---|
| 长坂山道 | 三式蓄势 → 闪避反击 → Q 破盾 | 当前用三组教学敌群、油车、枪势提示和营火选战法 |
| 荒村 | 救人或先赶路 | 当前支线解锁医者；后续强化求救声与远处可见的救援情境 |
| 破庙 | 读招与第一次单挑 | 当前夏侯恩与青釭奖励；后续按人工失败原因调窗口 |
| 井畔 | 保护目标，重新部署随军 | 当前两波保护医者、可改写结局；后续减少站桩等待的演出空档 |
| 粮道 | 直接突围或先破后勤 | 当前焚粮改变北桥弓阵和路线；保留明确风险/收益 |
| 北桥 | 队伍掩护 → 赵云单挑 → 渡桥 | 当前战报直接引向汉水，避免回菜单中断征程 |
| 汉水林道/北山 | 用已选打法对付双刀、双发弩、铁盾 | 当前可换营火战法；黄忠战斗演出仍待制作 |
| 乱石归途 | 主动开路、护车与回救伤兵 | 当前提前清路和安全追赶，减少纯等车 |
| 孤营 | 藏兵、门前压阵、判断鼓点 | 当前状态/人数/时机清楚，错过仍有可通关替代路线 |
| 河湾 | 把前段决策变成可见优势 | 继承同一批退军伤亡，齐射与焚毁火箭改变压力 |
| 铁营 | 将已学操作用于两阶段督军 | 继续保留钩拉、延迟回斧和破势；后续人工校准节奏 |

## 下一轮验收与边界

本轮优先把战斗循环、战法选择、护车节奏和双章衔接做实。下一轮需要完整人工试玩普通难度，记录：第一次理解枪势需要多久、是否仍能只按 J 获胜、营火选择是否改变打法、粮车等候时间、鼓点失败原因、Boss 重试次数。自动加速清群只验证流程，不代替这些体验判断。

暂不扩地图面积、等级刷怪、随机装备或新一章；先让现有十二区各自有明确目的。后续内容优先是黄忠参与接应战、救援演出和声音指引，随后才扩招式与新敌种。

## 开发入口

- `grain_cart.gd`、`tactic_director.gd`、`chapter2.json`：提前路障触发、跟进速度、状态提示。
- 四个新专项：`combat_loop_verify`、`battle_art_verify`、`hanshui_pacing_verify`、`chapter_progression_verify`。与原十三组一起进入 `Run-Checks`。
