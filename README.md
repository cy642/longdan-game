# 龙胆：逆命三国

宣传副标题：**重生之我在三国当赵子龙**。第一章「长坂逆命」的2D俯视角动作冒险原型，当前专注电脑版，沿用用户选定的Q版赵云形象。

## 打开游玩

- 在线试玩：[GitHub Pages](https://cy642.github.io/longdan-game/)。
- 电脑本地：双击 `index.html`，或在项目目录启动本地静态预览服务。
- 此版本使用键盘与鼠标操作，打开后直接进入标题画面。暂停中可查看完整操作说明或全屏游玩。
- 线上入口内含样式和脚本，角色图片从同目录 `assets/` 载入，可由浏览器独立缓存；游戏不调用外部接口。本地使用时保留 `assets/` 文件夹。
- 需要单独复制一个文件游玩时，运行 `node build.mjs --offline` 生成 `longdan-offline.html`，六张图片全部嵌入其中，无需联网。
- 存档保存在当前浏览器、当前打开地址下。不同浏览器、端口或地址之间不自动同步。存档损坏时仍可开始新游戏。

需要本地预览时，在项目目录运行：

```powershell
python -m http.server 8767 --bind 127.0.0.1
```

本地预览地址：`http://127.0.0.1:8767/`。

## 操控

| 行动 | 键盘 / 鼠标 |
|---|---|
| 移动 | WASD / 方向键 |
| 龙枪三式 | J / 鼠标左键，可按住；鼠标指向攻击方向 |
| 闪避 | 空格 / K |
| 横扫破阵 | Q / 鼠标右键 |
| 青釭断势 | R，夺剑后解锁、满战意发动 |
| 行军药 | F |
| 救援 / 休整 / 前进 | E |
| 集合 / 守点 / 冲阵 | 1 / 2 / 3 |
| 军图 / 暂停 | M / Esc |

闪避消耗16气力，破阵消耗30气力。精准闪避必须避到敌人实际出手的攻击，成功后1.2秒内出枪会变为回马枪。第三式和重招收招较长。行军药有服用时间，受击会打断，营火补满三份。

出枪、闪避、破阵与青釭在动作或冷却结束前的最后0.12秒接受一次短按缓冲，动作允许时自动执行一次；过早的短按不保留。打开军图、暂停、切换区域和进入对白会清空待执行输入。键盘连击优先继续攻击仍在近处的同一目标，鼠标指向可以主动改向。

红色预警包含敌人实际出手的范围与冲枪经过的整段路径，实线表示方向已锁定。弓手箭路会被建筑和完整油车遮挡。连招中途收招仍会提示下一式，整套连招结束后才显示可反击的提示。

## 第一章流程

1. 溃军山道：开场记忆；三场遭遇依次提示连击、闪避与破盾，出口的油车可以借势破阵。技巧尝试不作为前进门槛；清开山道后在营火休整。
2. 荒村小巷：剑兵、枪兵、盾兵和弓手；西巷可救医者与三名百姓。
3. 破庙夺剑：单挑夏侯恩，观察双剑、延迟重斩和转身横斩；获得青釭断势与荒村侧门捷径。
4. 井畔旧宅：找到阿斗与糜夫人。可以先护阿斗撤离，也可请医者施救，守住两波追兵。缺少医者时，可原路返回破庙，经侧门回荒村。
5. 粮道岔口：粮营油车提供另一处环境战术；挑战可选的盾阵校尉，焚粮撤走北桥弓阵、开放东侧道。前往北桥前可回头补救援。
6. 北桥决战：三名随军掩护桥头突围，随后护送百姓与担架，赵云单挑张郃。半血加入回身反刺和延迟追枪，敌将败退后渡桥重逢。

结尾分别记录糜夫人存活、百姓获救与粮道截断。主线不要求完成支线。进入北桥前有明确的返回截止提示。

随军固定三人，只在井畔营救、桥头突围中参与战斗；普通探索时待命，正式单挑时负责护送。他们以牵制和掩护为主，单人攻击为3.5伤害、间隔1.8秒，并且不能自行完成击杀。倒地随军在战斗结束或重试后恢复。

山道与粮营各有一辆可攻击的油车。真正的命中帧会点燃油车，0.9秒后爆裂，红圈预示危险范围；近处敌人受到85伤害与破盾，赵云及参与战斗的友军受到28伤害。及时撤出红圈或闪避可避免受伤。爆裂仅生效一次，残骸不再阻挡移动；未完成的遭遇在重试时恢复油车，已清开的遭遇保留完成状态。

## 进度与重试

- 山道、破庙、北桥三处营火恢复体力、气力与行军药，并记录落脚点。
- 区域入口、正式敌将入口、井畔营救入口也保存进度。
- 死亡后点击「重新握枪」，当前未完成战斗重置，已救百姓、已夺青釭、已完成支线和已清开的遭遇保留。
- 刷新后「继续逆命」从最近入口继续。首次开场、第一次敌将入阵有剧情；重试不重复敌将开场。

## 后续扩展

关卡、战斗和输入已拆开；当前开发重点为电脑版，后续需要移动端时可另外接入输入与界面：

- `stages.js`：区域、道路、场景、敌群、出入口，以及招式的蓄力 / 命中 / 收招参数。
- `campaign.js`：战斗、操作缓冲、敌将连招、破势、油车互动、情境引导、军令、路径寻找、任务条件与兼容旧进度的 `SaveSnapshot v1`。
- `game.js`：键鼠输入、界面、音效、镜头、浏览器保存和渲染。
- `visuals.js`：角色图集解析、统一角色比例、八方向步行与出枪、场景与特效绘制。
- `scene-art.js`：六区域地表、道路车辙、碎石苔草、破庙庭院、桥面与水纹；入场缓存地形和场景缩略图。
- `combat-art.js`：枪芒、横扫弧光、青釭龙形剑气、命中火花与闪避残影；特效几何跟随实际招式方向和范围。
- `shell.html`、`styles.css`：电脑版布局。
- `build.mjs`：生成线上轻量入口；`--offline` 将源码与六张图片打包成离线单文件。
- `verify.mjs`：关键战斗和章节分支的自动检查。

后续可以添加区域定义、招式、敌将连招和剧情条件；新章节还需接入目标指引、进度条件与保存版本。当前没有账号、联网多人或跨设备云存档。

## 素材与验证

八方向步行图集 `assets/zhaoyun-walk-v2.png`，以及盾兵、校尉、张郃、医者、糜夫人和随军的 `assets/chapter1-units-v2.png`。美术生成提示词及使用方式见 `assets/ART-NOTES.md`。脚底与阴影贴地，步伐和落脚音跟随实际行进距离。

新增 `assets/zhaoyun-attack-v3.png` 八方向出枪图集，生成提示词和实际方向映射见 [ATTACK-V3-NOTES](assets/ATTACK-V3-NOTES.md)。站立、走动、出枪和死亡以头部尺度统一缩放，避免长枪、飘带或蹲姿改变人物大小；向下枪尖低于鞋底时使用单独的脚底锚点。每个方向都有蓄势和刺击姿势，按真实招式的蓄力、命中与收招时段切换；横扫与青釭有身体转动，横向保留原有宽幅横扫姿势。

地图增加了区域配色、道路边缘与车辙、树下落叶和苔草、荒村残骸、破庙裂纹石板与地纹、旧宅院落、粮营辎重和北桥流动水纹。军图使用当前场景缩略图，并显示目标环、面朝方向和小地图视野范围。

龙枪三式有银蓝枪芒与第三式金色弧光，横扫破阵有环形锋芒，青釭断势有聚气、龙形剑气和局部招式题字。命中触发短暂顿帧和火花，破盾有碎光，闪避留下自动消散的角色残影。特效余光不会追加伤害，旧版进度仍可继续。暂停菜单可以切换「完整 / 柔和」特效，柔和模式去除震屏和顿帧、降低光效，并默认尊重系统减少动态效果的偏好。

目前步行每个方向两帧，普通敌兵仍以单姿态和动作倾斜为主。更连续的战斗动作、区域建筑和完整音乐还可以继续打磨。20–30分钟是第一章的设计目标，实际节奏仍需要玩家完整试玩校准。

```powershell
node build.mjs
node verify.mjs
```

自动检查覆盖输入缓冲及过期、连击目标保持、冲枪预警与跨帧判定、山道引导、油车命中与倒计时、爆裂与重试、箭路遮挡和旧存档兼容，以及实际命中帧、服药打断、精准闪避、同时出手限制、破盾、随军输出限制、六区域、两条救援路线、两位敌将、二阶段、焚粮部署、绕障碍与木桥路径、离线素材完整性。
