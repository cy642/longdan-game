# 龙胆：逆命三国

开发主线为 **Godot 4.7.2 / GDScript 原生 2D 电脑版**。第一章「长坂逆命」收尾，第二章「汉水孤营」已接入六区主路、军令计策、粮车护送、新敌兵和铁面督军。标题可选择任一章，分别继续、重玩和查看战报。

**0.4.0 地图身份打磨（2026-10-22）**：十二个区域分别安排道路宽度、土质、植物剪影与叙事地标。荒村的受损民居、破庙的残缺院落、井庭生活痕迹、粮道车辙、汉水竹林与孤营夯土不再只靠章节色调区分。可编辑源和逐区约束见 [地图美术规范](docs/MAP-ART-DIRECTION.md)；本轮回归、性能、最终图形与导出上线状态待完成后记录在 [开发记录](CLOUD-POLISH.md)。

**0.3.1 玩法打磨**：修复入区提示过早消失；山道清兵后首次引导营火选战法，仍可直接前进。闪避和 Q 显示缺气、冷却与真实可用状态；敌人头顶区分稳势、破势和整套收招。北山接应战靠近黄忠按 **3** 请求一箭援护，敌人最后一击仍由赵云完成。

上一轮的三格枪势、连锋/游龙战法、主动清路护车继续保留。**第一章通关后，在战报点击“继续征程 · 汉水孤营”进入第二章**；首次继承难度和战法，已有第二章进度继续原检查点。整体规划与当前实现见 [可玩性计划](docs/PLAYABILITY-PLAN.md)。

本轮变更、验证范围与发布记录见 [开发记录](CLOUD-POLISH.md)，工程结构、构建和美术重建见 [Godot 开发说明](godot/README.md)。根目录 Canvas 原型继续保留；新的关卡开发以 `godot/` 为准。

宣传副标题：**重生之我在三国当赵子龙**。2D 俯视角动作冒险，当前专注电脑版，沿用用户选定的 Q 版赵云形象。

在线试玩：[Godot 电脑版](https://cy642.github.io/longdan-game/godot-play/)。首次下载引擎与素材，使用电脑键鼠；Windows 本地版导出为 `builds/windows/Longdan.exe`，不纳入 Git。

赵云待机、行走和攻击共用固定模型比例，倒地素材按原画密度单独校准，营门退兵/擂鼓阶段保持同一镜头倍率。地图的这一轮区分深入到每区的路形、地表和景物：山道有岩层，荒村有烟熏街巷，破庙有被侵蚀的石院，井畔是旧宅院落；汉水的竹林、粮道、乱石、营门、河湾和铁营各有独立剪影与地面用途。

两章十二区各使用一张烘焙地表，树木、岩石和建筑使用共用的 47 帧、2048 × 1536 景物图集（此前为 33 帧、1920 × 1920）。美术源与实体碰撞、剧情坐标分开，原有通路和旧存档格式沿用；改图后仍须用地图基线和实画面核对。使用本机 Godot 打开 `godot/project.godot` 按 F5 试玩；打开 `tests/map_tour.tscn` 按 F6，可用 Tab 切章、F1–F6 巡览各区，不写入玩家存档。

脚步声使用独立轻声通道，暂停页可单独关闭；第一章保留六区、两名敌将与三条可选命运。最新收尾修复随军绕帐篷卡住、存档磁盘回读与部分键盘的 Esc/J 识别，并修正缩放后交互物动画裁剪。

## 当前 Godot 版本：第二章「汉水孤营」

1. **汉水林道**：整队出发，学习双刀与双发弩兵的出手节奏。
2. **北山粮道**：击退守军、接应黄忠；靠近黄忠按 3 请求援射，抓住敌人停顿切入；可去东岗焚毁火箭辎重。
3. **乱石归途**：护送真实可受击的粮车通过两处路障；西侧可回救张著和伤兵。

## 旧 Canvas 原型：打开游玩

以下操作、流程与 JavaScript 文件说明对应仓库根目录的历史 Canvas 版本。第二章与后续 Godot 开发请使用上面的入口。

- 在线试玩：[GitHub Pages](https://cy642.github.io/longdan-game/)。
- 电脑本地：双击 `index.html`，或在项目目录启动本地静态预览服务。
- 此版本使用键盘与鼠标操作，打开后直接进入标题画面。暂停中可查看完整操作说明或全屏游玩。
- 线上入口内含样式和脚本，角色图片从同目录 `assets/` 载入，可由浏览器独立缓存；游戏不调用外部接口。本地使用时保留 `assets/` 文件夹。
- 需要单独复制一个文件游玩时，运行 `node build.mjs --offline` 生成 `longdan-offline.html`，六张图片全部嵌入其中，无需联网。
- 存档保存在当前浏览器、当前打开地址下。不同浏览器、端口或地址之间不自动同步。存档损坏时仍可开始新游戏。

需要本地预览时，在项目目录运行：

```powershell
python -m http.server 8767 --bind 127.0.0.1
```

本地预览地址：`http://127.0.0.1:8767/`。

## 操控

| 行动 | 键盘 / 鼠标 |
|---|---|
| 移动 | WASD / 方向键 |
| 龙枪三式 | J / 鼠标左键，可按住；鼠标指向攻击方向 |
| 闪避 | 空格 / K |
| 横扫破阵 | Q / 鼠标右键 |
| 青釭断势 | R，夺剑后解锁、满战意发动 |
| 行军药 | F |
| 救援 / 休整 / 前进 | E |
| 集合 / 守点 / 冲阵 | 1 / 2 / 3 |
| 军图 / 暂停 | M / Esc |

闪避消耗16气力，破阵消耗30气力。精准闪避必须避到敌人实际出手的攻击，成功后1.2秒内出枪会变为回马枪。第三式和重招收招较长。行军药有服用时间，受击会打断，营火补满三份。

服药时底部显示剩余时间与进度条，完成后显示「体力已恢复」；短暂掉帧跨过回血时点也会正确恢复一次。完整盾防的正面格挡保留盾兵起手，普通枪不会持续把盾兵打断；使用横扫破盾、绕后攻击或积满破势来创造反击机会。

出枪、闪避、破阵与青釭在动作或冷却结束前的最后0.12秒接受一次短按缓冲，动作允许时自动执行一次；过早的短按不保留。打开军图、暂停、切换区域和进入对白会清空待执行输入。键盘连击优先继续攻击仍在近处的同一目标，鼠标指向可以主动改向。

红色预警包含敌人实际出手的范围与冲枪经过的整段路径，实线表示方向已锁定。弓手箭路会被建筑和完整油车遮挡。连招中途收招仍会提示下一式，整套连招结束后才显示可反击的提示。

按住鼠标左键持续攻击时，瞄准始终跟随鼠标。敌人头顶会短暂显示破势、盾防已破或变招状态；击退一组守军后提示下一步战令。掉落药包在受伤且靠近时自动拾取，最多恢复18体力，并显示实际恢复量、回血光环与声音；满血时保留药包，直到自然消失。镜头跟随按时间平滑，适配不同刷新率。

左右鼠标键可组合使用，动作尾段的右键会按既有输入缓冲接横扫，松开右键仍可保持左键连击。离开窗口、取消指针或失去鼠标捕获后会清除持续攻击。

## 第一章流程

1. 溃军山道：开场记忆；三场遭遇依次提示连击、闪避与破盾，出口的油车可以借势破阵。技巧尝试不作为前进门槛；清开山道后在营火休整。
2. 荒村小巷：剑兵、枪兵、盾兵和弓手；西巷可救医者与三名百姓。
3. 破庙夺剑：单挑夏侯恩，观察双剑、延迟重斩和转身横斩；获得青釭断势与荒村侧门捷径。
4. 井畔旧宅：找到阿斗与糜夫人。可以先护阿斗撤离，也可请医者施救，守住两波追兵。缺少医者时，可原路返回破庙，经侧门回荒村。
5. 粮道岔口：粮营油车提供另一处环境战术；挑战可选的盾阵校尉，焚粮撤走北桥弓阵、开放东侧道。前往北桥前可回头补救援。
6. 北桥决战：三名随军掩护桥头突围，随后护送百姓与担架，赵云单挑张郃。半血加入回身反刺和延迟追枪，敌将败退后渡桥重逢。

结尾分别记录糜夫人存活、百姓获救与粮道截断，并显示支线完成数与未完成命运的重玩提示。主线不要求完成支线。进入北桥前有明确的返回截止提示。金色任务指引优先指向阻挡当前任务的存活守军，清开后再指向互动点，避免出口被阻挡时找不到漏掉的敌人。

随军固定三人，只在井畔营救、桥头突围中参与战斗；普通探索时待命，正式单挑时负责护送。他们以牵制和掩护为主，单人攻击为3.5伤害、间隔1.8秒，并且不能自行完成击杀。倒地随军在战斗结束或重试后恢复。

山道与粮营各有一辆可攻击的油车。真正的命中帧会点燃油车，0.9秒后爆裂，红圈预示危险范围；近处敌人受到85伤害与破盾，赵云及参与战斗的友军受到28伤害。及时撤出红圈或闪避可避免受伤。爆裂仅生效一次，残骸不再阻挡移动；未完成的遭遇在重试时恢复油车，已清开的遭遇保留完成状态。

## 进度与重试

- 山道、破庙、北桥三处营火恢复体力、气力与行军药，并记录落脚点。
- 区域入口、正式敌将入口、井畔营救入口也保存进度。
- 死亡后点击「重新握枪」，当前未完成战斗重置，已救百姓、已夺青釭、已完成支线和已清开的遭遇保留。
- 刷新后「继续逆命」从最近入口继续。首次开场、第一次敌将入阵有剧情；重试不重复敌将开场。
- 通关战报自动保存在同一浏览器，回到标题或刷新后可点击「查看长坂战报」，旧版通关存档也可回看。
- 新征程会替换当前进度与战报，开始前可以取消；从暂停或结局重开时保留当前战斗难度。
- 小地图下方显示保存状态。如果浏览器禁止保存，当前页面仍保留本次进度，回标题后可继续；刷新或关闭页面会丢失这份临时进度，界面会明确提示。保存失败时重开也需要确认。
- 井畔救援分别显示施救进度、当前波次与剩余追兵。施救准备完成后，仍须击退两波追兵才能救出糜夫人。

## 后续扩展

关卡、战斗和输入已拆开；当前开发重点为电脑版，后续需要移动端时可另外接入输入与界面：

- `stages.js`：区域、道路、场景、敌群、出入口，以及招式的蓄力 / 命中 / 收招参数。
- `campaign.js`：战斗、操作缓冲、敌将连招、破势、油车互动、情境引导、军令、路径寻找、任务条件与兼容旧进度的 `SaveSnapshot v1`。
- `game.js`：键鼠输入、界面、音效、镜头、浏览器保存和渲染。
- `visuals.js`：角色图集解析、统一角色比例、八方向步行与出枪、场景与特效绘制。
- `scene-art.js`：六区域地表、道路车辙、碎石苔草、破庙庭院、桥面与水纹；入场缓存地形和场景缩略图。
- `combat-art.js`：枪芒、横扫弧光、青釭龙形剑气、命中火花与闪避残影；特效几何跟随实际招式方向和范围。
- `shell.html`、`styles.css`：电脑版布局。
- `build.mjs`：生成线上轻量入口；`--offline` 将源码与六张图片打包成离线单文件。
- `verify.mjs`：关键战斗和章节分支的自动检查。
- `verify-ui.mjs`：实际界面事件的鼠标组合键、暂停清理、保存失败回退、重开确认和救援反馈检查。

后续可以添加区域定义、招式、敌将连招和剧情条件；新章节还需接入目标指引、进度条件与保存版本。当前没有账号、联网多人或跨设备云存档。

龙枪三式有银蓝枪芒与第三式金色弧光，横扫破阵有环形锋芒，青釭断势有聚气、龙形剑气和局部招式题字。敌人依照真实蓄力、出手和收招时段压身、前扑与回稳，受击和破势时也有回弹；剑斩、枪突、盾击、弓射、夏侯恩双剑及张郃冲枪使用不同的局部锋芒与发射效果，张郃二阶段有变招气浪。命中触发短暂顿帧和火花，破盾有碎光，闪避留下自动消散的角色残影。特效余光不会追加伤害，旧版进度仍可继续。暂停菜单可以切换「完整 / 柔和」特效，柔和模式去除震屏和顿帧、降低光效，并默认尊重系统减少动态效果的偏好。
