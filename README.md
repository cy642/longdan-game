# 龙胆：逆命三国

宣传副标题：**重生之我在三国当赵子龙**。第一章「长坂逆命」的2D俯视角动作冒险原型，沿用用户选定的Q版赵云形象。

## 打开游玩

- 在线版：部署到 GitHub Pages 后，打开 `https://cy642.github.io/longdan-game/`。
- 电脑本地：双击 `index.html`，或在项目目录启动本地静态预览服务。
- 手机本地预览：电脑和手机连接同一 Wi-Fi，在手机浏览器打开电脑显示的局域网地址；局域网预览需要电脑保持开机、试玩服务保持运行。
- 此版本是浏览器游戏。第一屏选择手机版或电脑版；暂停中可切换，手机版推荐横屏，竖屏也可操作。
- 所有角色图片、样式和脚本都嵌入 `index.html`，游戏不调用外部接口。单独复制这个文件即可保留素材和玩法。
- 存档保存在当前浏览器、当前打开地址下。电脑与手机各自保存；不同浏览器、端口或地址之间不自动同步。存档损坏时仍可开始新游戏。

需要重新开启手机预览时，在本目录运行：

```powershell
python -m http.server 8767 --bind 0.0.0.0 --directory 'D:\gpt\longdan-game'
```

## 操控

| 行动 | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD / 方向键 | 左下摇杆 |
| 龙枪三式 | J / 鼠标左键，可按住 | 出枪，可按住 |
| 闪避 | 空格 / K | 闪避 |
| 横扫破阵 | Q / 鼠标右键 | 破阵 |
| 青釭断势 | R，夺剑后解锁、满战意发动 | 青釭 |
| 行军药 | F | 行军药 |
| 救援 / 休整 / 前进 | E | 互动 |
| 集合 / 守点 / 冲阵 | 1 / 2 / 3 | 军令按钮 |
| 军图 / 暂停 | M / Esc | 顶部军图 / 暂停 |

闪避消耗16气力，破阵消耗30气力。精准闪避必须避到敌人实际出手的攻击，成功后1.2秒内出枪会变为回马枪。第三式和重招收招较长。行军药有服用时间，受击会打断，营火补满三份。

## 第一章流程

1. 溃军山道：开场记忆、基础出枪、连击与闪避，山道营火。
2. 荒村小巷：剑兵、枪兵、盾兵和弓手；西巷可救医者与三名百姓。
3. 破庙夺剑：单挑夏侯恩，观察双剑、延迟重斩和转身横斩；获得青釭断势与荒村侧门捷径。
4. 井畔旧宅：找到阿斗与糜夫人。可以先护阿斗撤离，也可请医者施救，守住两波追兵。缺少医者时，可原路返回破庙，经侧门回荒村。
5. 粮道岔口：挑战可选的盾阵校尉，焚粮撤走北桥弓阵、开放东侧道。前往北桥前可回头补救援。
6. 北桥决战：三名随军掩护桥头突围，随后护送百姓与担架，赵云单挑张郃。半血加入回身反刺和延迟追枪，敌将败退后渡桥重逢。

结尾分别记录糜夫人存活、百姓获救与粮道截断。主线不要求完成支线。进入北桥前有明确的返回截止提示。

随军固定三人，只在井畔营救、桥头突围中参与战斗；普通探索时待命，正式单挑时负责护送。他们以牵制和掩护为主，单人攻击为3.5伤害、间隔1.8秒，并且不能自行完成击杀。倒地随军在战斗结束或重试后恢复。

## 进度与重试

- 山道、破庙、北桥三处营火恢复体力、气力与行军药，并记录落脚点。
- 区域入口、正式敌将入口、井畔营救入口也保存进度。
- 死亡后点击「重新握枪」，当前未完成战斗重置，已救百姓、已夺青釭、已完成支线和已清开的遭遇保留。
- 刷新后「继续逆命」从最近入口继续。首次开场、第一次敌将入阵有剧情；重试不重复敌将开场。

## 后续扩展

关卡、战斗和输入已拆开，手机与电脑共用同一套规则：

- `stages.js`：区域、道路、场景、敌群、出入口，以及招式的蓄力 / 命中 / 收招参数。
- `campaign.js`：战斗、敌将连招、破势、军令、路径寻找、任务条件与 `SaveSnapshot v1`。
- `game.js`：键鼠 / 多指触控输入、界面、音效、镜头、浏览器保存和渲染。
- `visuals.js`：角色图集解析、八方向步行、场景与特效绘制。
- `shell.html`、`styles.css`：电脑和手机布局。
- `build.mjs`：将源码与五张图片打包成单文件。
- `verify.mjs`：关键战斗和章节分支的自动检查。

后续可以添加区域定义、招式、敌将连招和剧情条件；新章节还需接入目标指引、进度条件与保存版本。当前没有账号、联网多人或跨设备云存档。
